Kinds:
- **empty pin** `__asm__("" : ...)` -- zero instructions; a scheduling / register-allocation fence. C-source-only debt.
- **real asm** -- instruction or directive text. Allowed only for cop0, GTE macros, syscalls, MMIO and file-scope section/label plumbing.
- **linkage alias** `decl asm("mangled")` -- a symbol name on a declaration, no code (~400, almost all in `frontend/*_externs.h`). Not debt.
- **pure-C fence** -- asm-free codegen levers: an empty or single-statement `do { } while (0)` wrapper (scheduling barrier / loop-weight dial), the absorption identity `x | (x & k)` / `x & (x | k)` (reference-count dial), and OR/AND self-repeats `x | v | v`. Valid C that compiles to nothing, but not natural source; counted so they stay visible.
