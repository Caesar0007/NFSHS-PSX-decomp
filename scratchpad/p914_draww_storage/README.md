The source/interface/default-threshold candidate passes all **35 base
functions and 361 branches**. Its repaired USA consumer passes all **35
actual USA instruction-stream checks and 359 internal branches**. The USA

remain explicit. No invented replacement compatibility views are introduced.

## Original information restored

- Missing MATRIX diagonal values m11/m22 become 4096, correcting exactly two
  bytes in `gIdentTemplate`.
- Existing `stackSpeedUpEnbabledFlag` explicitly initializes to zero so its
  CPE-loaded cell precedes the two real eight-byte static arrays.
- Cars pointer arrays are correctly declared `[9]`, not `[2]`.
- Skidmark pointer array is correctly `[2]`, retiring the false `[1]` workaround.
- Night's incomplete caller array declaration is type-compatible with its
  native `[2]` owner and preserves the required address materialization.
  Original caller-bound spelling is absent from DrawW SYM and remains unproved.
- The whole TU uses the installed compiler's default G8 behavior. Omitting
  `-G` from the actual CC1PL command produces the same whole object as explicit
  G8. Native eligibility constrains `8 <= G < 24`; historical command spelling
  is not uniquely recovered. This is not a per-function matching flag.

No ordinary function body is rewritten in the base TU. All 35 emitted debug
declaration/type/dimension/block/PC-label records and all source-line partitions
remain unchanged. Four HIGH/LO-to-`la` unassembled spelling changes are accounted
for separately; machine instructions and all branch checks remain exact.
The root's final-comment source/header stage is independently re-gated.

The USA patch replaces six obsolete view/name families with existing native

oracles and the other 33 actual USA function slices are checked, not inferred
